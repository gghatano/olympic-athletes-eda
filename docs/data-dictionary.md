# データ辞書

対象パッケージ: `olympicAthletes` 0.5.10（CRAN）
原典: [Olympedia.org](https://www.olympedia.org/)
確認日: 2026-08-01

## 収録データセット

パッケージは 14 個のデータセットを持つ。実質的な本体は最初の 3 つで、
残りは `olympic_athletes` を競技や大会で絞った教材向けの部分集合。

| データセット | 行数 | 粒度 | 用途 |
|---|---:|---|---|
| `olympic_athletes` | 315,094 | 選手 × 大会 × 種目 | 本体。参加・体格・性別・メダル |
| `medal_table` | 1,929 | 大会 × NOC | **公式**メダル集計。国別メダル数はこれを正とする |
| `editions` | 62 | 大会 | 開催地・日程・参加者数・種目数・注記 |
| `athletics_athletes` | 43,062 | 同上 | 陸上のみの部分集合 |
| `gymnastics_athletes` | 29,413 | 同上 | 体操のみ |
| `basketball_athletes` | 5,159 | 同上 | バスケットボールのみ |
| `volleyball_athletes` | 4,792 | 同上 | バレーボールのみ |
| `curling_athletes` | 961 | 同上 | カーリングのみ |
| `art_competitions_athletes` | — | 同上 | 芸術競技（1912-1948） |
| `team_sport_athletes` | — | 同上 | 団体競技 3 種 |
| `olympic_athletes_2024` | — | 同上 | パリ 2024 のみ |
| `usa_summer_medals` | — | 大会 | USA の夏季メダル表 |
| `paris_2024_top_medals` | — | NOC | パリ 2024 上位 10 か国 |
| `season_counts` | — | シーズン | 行数の事前集計 |

本リポジトリは `olympic_athletes` / `medal_table` / `editions` の 3 つだけを使う。
部分集合は本体から再現できるため、二重管理を避けた。

## `olympic_athletes`（16 列）

粒度は **1 行 = 1 人の選手が 1 大会の 1 種目に出場したこと**。
同じ選手が複数種目に出れば複数行、団体競技ならチーム全員分の行がある。

| 列 | 型 | 欠損率 | 値の範囲・備考 |
|---|---|---:|---|
| `id` | int | 0% | 選手 ID。157,377 人。`name` と 1 対 1（同名別人が 839 件あるため `name` より `id` が信頼できる） |
| `name` | chr | 0% | 選手名。156,538 通り |
| `sex` | chr | 0% | `M` / `F` の 2 値。**全期間で欠損なし** |
| `age` | int | 3.0% | 10-97 歳。中央値 25。欠損は 1950 年代以前に集中 |
| `height` | num | 25.8% | 127-226 cm。**欠損の年代偏りが大きい**（下記） |
| `weight` | num | 27.6% | 25-214 kg。同上 |
| `team` | chr | 1.5% | チーム名。セーリングでは艇名が入る（例 `Martha-1`）。1,395 通り |
| `noc` | chr | 1.2% | 3 文字の国内オリンピック委員会コード。236 通り。欠損は 2018 年以降のみ |
| `games` | chr | 0% | `"1896 Summer"` 形式。56 大会 |
| `year` | int | 0% | 1896-2026。40 通り（1992 年までは夏冬が同年開催） |
| `season` | chr | 0% | `Summer`（250,747 行） / `Winter`（64,347 行） |
| `city_local_latin` | chr | 0% | 開催都市（現地表記のラテン文字化。例 `Athína`） |
| `city_english` | chr | 0% | 開催都市（英語。例 `Athens`）。44 都市 |
| `sport` | chr | 0% | 競技。69 通り |
| `event` | chr | 0% | 種目。1,270 通り。競技名と性別区分を含む（例 `Athletics Men's 100 metres`） |
| `medal` | chr | 86.0% | `Gold` / `Silver` / `Bronze` / NA。**NA = メダルなし**（欠損値ではない） |

### 年代範囲

- 夏季: 1896 アテネ 〜 2024 パリ（31 大会）
- 冬季: 1924 シャモニー 〜 2026 ミラノ・コルティナ（25 大会）
- 中止大会（1916 / 1940 / 1944）は `editions` にのみ行があり、選手データには行がない
- 1906 アテネ中間大会は IOC 非公認だが収録されている（`editions$notes` に明記）

## `medal_table`（11 列）

粒度は **1 行 = 1 大会 × 1 NOC**。IOC 方式（団体競技も 1 種目 1 メダル）で
検証済みの公式集計。

| 列 | 型 | 備考 |
|---|---|---|
| `edition_id` | int | `editions` への外部キー |
| `games`, `year`, `season` | chr/int/chr | 大会 |
| `noc` | chr | NOC コード |
| `country` | chr | 国名（英語） |
| `gold`, `silver`, `bronze`, `total` | int | メダル数 |
| `notes` | chr | 注記（多くは空文字列。NA ではない） |

## `editions`（15 列）

粒度は **1 行 = 1 大会**（中止大会・非公認大会を含む 62 行）。

| 列 | 型 | 備考 |
|---|---|---|
| `edition_id` | int | 主キー |
| `games`, `year`, `season` | chr/int/chr | 大会 |
| `city_local_latin`, `city_english`, `country` | chr | 開催地 |
| `opening_ceremony`, `closing_ceremony` | Date | 初期大会は NA が多い |
| `participants`, `nocs`, `medal_events`, `disciplines` | int | 規模。中止大会は全て NA |
| `notes` | chr | **文脈情報が豊富**。ボイコット、ドーピング処分、ROC/AIN の扱い、COVID 延期など |
| `source` | chr | Olympedia の該当 URL |

`country` は `medal_table$country` と表記が一致するため、開催国 → NOC の変換が
join だけでできる（62 大会すべて一致することを確認済み）。

## 特に注意する点

1. **`medal` の NA はメダルなし**。`is.na(medal)` を欠損として除外すると
   メダリストだけが残る。
2. **団体競技でメダル行が人数分ある**。選手行をそのまま数えると水増しになる
   （2024 夏の USA は選手行 195 に対し、種目単位では 99）。
3. **`(id, games, event)` の重複 1,480 行は多くが実在**。芸術競技の複数出品、
   セーリングで同一選手が複数艇に乗るケースなど。全列一致の完全重複 1,385 行のみ
   除去してよい。
4. **1 種目のメダルが 4 件になることがある**。柔道・ボクシング等の銅 2 個授与。
5. **`team` は国名とは限らない**。セーリングでは艇名。国の分析には `noc` を使う。
